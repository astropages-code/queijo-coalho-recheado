# Landing Page: Queijo Coalho Recheado (Queijo de Casa)

Landing page de alta conversão, responsiva e pixel-perfect construída em HTML5 semântico, CSS puro e JavaScript nativo.

## Stack
- HTML5 Semântico
- CSS3 (Variáveis CSS, Flexbox/Grid, Mobile-First / Desktop-First híbrido)
- Vanilla JavaScript (Interatividade do FAQ Accordion e Smooth Scrolling)
- Google Fonts: Playfair Display + Plus Jakarta Sans

## Estrutura de Arquivos
- `index.html`: Marcação completa de todas as seções e blocos de conversão.
- `css/style.css`: Sistema de design, paleta de cores (verde floresta, marfim e terracota/laranja), tipografia e responsividade.
- `js/main.js`: Lógica do acordeão e rolagem fluida.
- `assets/images/crops/`: Imagens recortadas em alta definição da mentora, etapas, queijos e depoimentos.
- `assets/images/matriz/`: Matriz original em alta definição.
- `assets/images/slices/`: Fatias completas de referência.
